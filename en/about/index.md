## Sungwon Kim

Backend Engineer focused on performance improvement, realtime systems, data pipeline control, and failure recovery.

I develop services with Java and Spring Boot, analyze PostgreSQL/TimescaleDB performance, and design realtime collaboration and recovery using WebSocket, Redis, and Kafka. I also use Go and Python to build data collection, ETL, and Worker control flows.

I aim to make problems visible through measurements and state, verify improvements and recovery under comparable conditions, and document the evidence.
